# متجري | My Store

متجر إلكتروني مع لوحة تحكم، مبني بـ React كمشروع تعلم.

## المزايا
- تصفح المنتجات: بحث، فلترة بالفئة، ترتيب بالسعر
- صفحة تفاصيل المنتج ومنتجات مشابهة
- سلة مشتريات محفوظة في المتصفح
- إتمام الطلب مع التحقق من البيانات
- لوحة تحكم: إحصائيات ورسم بياني، وإدارة المنتجات (إضافة وتعديل وحذف) وإدارة الطلبات
- حماية لوحة التحكم بتسجيل دخول (للتجربة)

## التقنيات
React, Vite, React Router, Context API, Recharts

## التشغيل
npm install
npm run dev

## ملاحظات
- البيانات (المنتجات والطلبات والسلة) تُحفظ في localStorage، لذلك كل متصفح له بياناته الخاصة.
- تسجيل الدخول للتجربة فقط وليس أمناً حقيقياً.
- الخطوة التالية: ربط المشروع بخادم وقاعدة بيانات حقيقية.
